[변수]

같은 이름을 여러 역할에 사용하기

조건이 참일 때만 변수를 생성하기

평균 계산에서 정수 나눗셈 사용하기

변수를 만들기 전에 사용하기

변수 이름을 잘못 쓰기 (오타, 대소문자 구분 못함)

변수 이름과 문자열을 혼동하기 (print(name) 대신 print("name") 쓰기)

input()으로 받은 값을 숫자로 바꾸지 않고 계산하기

문자열과 숫자를 + 로 이어 붙이기

= 를 수학의 등호처럼 이해하기 (x = x + 1 이 이상하다고 생각하기)

계산만 하고 결과를 변수에 저장하지 않기 (x + 1 만 쓰고 x = x + 1 은 쓰지 않기)

두 변수의 값을 임시 변수 없이 서로 바꾸기 (a = b, b = a)

sum, max, list, str 같은 내장 함수 이름을 변수 이름으로 쓰기

변수 이름 규칙을 어기기 (숫자로 시작, 공백 포함, 특수문자 사용)

리스트를 b = a 로 복사하면 독립된 복사본이 생긴다고 생각하기


[조건문]

= 와 == 를 혼동하기

조건문 뒤에 콜론을 빠뜨리기

조건문 본문을 들여쓰기 하지 않거나 if 와 else 의 들여쓰기 위치를 맞추지 않기

else if 라고 쓰기 (elif 를 모르기)

elif 를 써야 할 곳에 if 를 여러 개 써서 여러 블록이 함께 실행되기

x == 1 or 2 처럼 or 조건을 잘못 쓰기

and 와 or 를 혼동하기 (범위 조건에 or 쓰기)

범위 조건을 수학식처럼 쓰지 못하고 한쪽만 검사하기 (x > 0 and x < 10 대신 x > 0)

경계값에서 < 와 <= 를 혼동하기

넓은 조건을 먼저 검사해서 뒤의 조건이 실행되지 않게 하기 (60 이상을 먼저 검사하고 90 이상을 나중에 검사하기)

조건이 겹치거나 빈틈이 생기게 나누기

input()으로 받은 문자열과 숫자를 == 로 비교하기

실수를 == 로 비교하기 (0.1 + 0.2 == 0.3)

나머지 연산자(%)와 나눗셈(/)을 혼동하기 (짝수·홀수, 배수 판별)

not 이 붙은 조건을 반대로 이해하기 (not (a and b) 를 not a and not b 로 바꾸기)


[반복문]

합계를 반복문 밖에서 초기화하기

합계를 반복문 안에서 출력하기

range(n) 이 1부터 n까지라고 생각하기 (실제로는 0부터 n-1)

range 의 끝 값이 포함된다고 생각하기 (range(1, 10) 이 10까지라고 생각하기)

반복 횟수가 한 번 더 많거나 적게 되기

while 문에서 조건을 바꾸는 문장을 빠뜨려 무한 반복하기

while 문 조건에 쓰는 변수를 먼저 초기화하지 않기

for 문이나 while 문 뒤에 콜론을 빠뜨리기

반복할 문장이 반복문 안에 들어가지 않게 들여쓰기 하기

개수를 셀 때 count += 1 대신 count = 1 이라고 쓰기

최댓값이나 최솟값의 초기값을 0으로 두기 (음수만 있을 때 틀림)

for i in 리스트 에서 i 가 인덱스가 아니라 값인데 인덱스처럼 쓰기 (a[i])

리스트 길이보다 한 칸 더 반복해서 인덱스 범위를 벗어나기 (range(len(a) + 1))

반복문 안에서 반복 변수(i)를 바꾸면 반복 횟수가 바뀐다고 생각하기

반복문으로 리스트를 순회하면서 그 리스트의 항목을 지우기

반복문 안에서 return 을 써서 첫 번째 반복에서 함수가 끝나기

while True 에서 break 를 빠뜨리거나 break 가 실행되지 않는 조건을 쓰기

지역 변수와 전역 변수를 혼동하기

함수 내부 변수를 함수 밖에서도 사용할 수 있다고 생각하기

조건에 따라 값을 반환하지 않는 경우가 생기게 하기

return 과 print 를 혼동하기

필요한 인자를 전달하지 않기

정의되지 않은 함수 호출하기

함수 이름을 변수 이름으로 덮어쓰기

함수 호출 시 괄호를 빠뜨리기

함수 본문을 들여쓰기 하지 않기

함수 정의를 호출하는 코드보다 아래에 쓰기

return 뒤에 코드를 써서 실행되지 않게 하기

return 이 없는 함수의 결과(None)를 변수에 저장해서 계산에 쓰기

함수가 반환한 값을 받지 않고 호출만 하기

전역 변수를 함수 안에서 바꾸려다 global 없이 오류가 나기

매개변수를 쓰지 않고 함수 밖의 변수를 그대로 쓰기

리스트를 함수에 넘겨 함수 안에서 바꿨을 때 원본도 바뀐다는 것을 이해하지 못하기

여러 값을 return 할 때 받는 쪽의 변수 개수를 맞추지 않기

[중첩 반복문]

줄바꿈 위치를 잘못 설정하기

행과 열을 반대로 이해하기

break 가 모든 반복문을 종료한다고 생각하기
