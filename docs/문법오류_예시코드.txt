문법 오류 검증 예시 코드
============================================================

코딩입문 중고등학생을 위한 단계적 피드백 웹서비스의 문법 오류 분석기(app/analyzer/syntax.py)가 잡는 19가지 오류마다 예시 코드를 하나씩 모았다.
'----- 코드 -----' 아래의 내용을 학생 화면의 코드 입력 칸에 그대로 붙여 넣고 제출하면, 그 오류에 해당하는
힌트가 나온다. 아래 힌트 문구는 기본값이며, 교사가 '오류별 힌트' 화면에서 고쳤다면 고친 문구가 나온다.

- 모든 예시는 실제 분석기로 확인했다 (Python 3.12 기준).
- 분석기는 파이썬이 알려 주는 첫 번째 문법 오류 하나만 다룬다.
- 줄 번호는 '----- 코드 -----' 바로 다음 줄을 1번 줄로 센 것이다.
- 붙여 넣을 때 줄 앞의 빈칸(들여쓰기)이 바뀌지 않게 주의한다. 들여쓰기 자체가 오류인 예시가 많다.


############################################################
# 조건문
############################################################

[1] 조건문 뒤에 콜론을 빠뜨리기
    오류 종류 id : cond.missing_colon
    잡히는 줄    : 2번 줄
----- 코드 -----
score = int(input("점수: "))
if score >= 60
    print("합격")
else:
    print("불합격")
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 `if`로 시작하는 줄을 읽다가 멈췄어요. 그 줄이 어디에서 끝나고 본문이 어디에서 시작하는지 알려 주는 표시를 찾지 못했어요.
  2. 의심 지점: 2번 줄의 맨 끝을 보세요. 기호 하나가 빠져 있어요.
  3. 힌트: `if`, `elif`, `else`로 시작하는 줄은 언제나 같은 기호로 끝나요. 전에 쓴 조건문이나 교과서 예시의 줄 끝과 견줘 보세요.


[2] else if 라고 쓰기
    오류 종류 id : cond.else_if
    잡히는 줄    : 4번 줄
----- 코드 -----
score = int(input("점수: "))
if score >= 90:
    print("A")
else if score >= 80:
    print("B")
else:
    print("C")
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 `else` 바로 뒤에 온 단어를 이해하지 못하고 멈췄어요. `else` 뒤에는 조건을 쓸 수 없어요.
  2. 의심 지점: 4번 줄을 시작하는 두 단어를 보세요.
  3. 힌트: '그렇지 않고, 만약 ~라면'을 뜻하는 단어가 파이썬에는 따로 하나 있어요. `else`와 `if`를 나란히 쓰는 대신 그 한 단어를 써야 해요.


[3] = 와 == 를 혼동하기
    오류 종류 id : cond.assign_in_if
    잡히는 줄    : 2번 줄
----- 코드 -----
answer = input("정답은? ")
if answer = "파이썬":
    print("맞았어요")
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 조건을 읽다가 멈췄어요. 조건 자리에는 참인지 거짓인지 물어보는 식이 와야 하는데, 값을 넣으라는 뜻의 기호가 들어 있어요.
  2. 의심 지점: 2번 줄 `if` 뒤의 조건에 쓴 `=` 기호를 보세요.
  3. 힌트: `=` 하나는 '오른쪽 값을 왼쪽 변수에 넣어라'는 뜻이에요. '두 값이 서로 같은가?'를 물을 때 쓰는 기호는 따로 있어요.


[4] 조건문 본문을 들여쓰기 하지 않기
    오류 종류 id : cond.body_not_indented
    잡히는 줄    : 3번 줄
----- 코드 -----
age = int(input("나이: "))
if age >= 14:
print("중학생 이상입니다")
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: `if` 줄 다음에는 `if`에 딸린 문장이 와야 하는데, 파이썬이 그런 문장을 찾지 못했어요.
  2. 의심 지점: 2번 줄 `if` 바로 아래에 있는 3번 줄을 보세요. `if`보다 안쪽에서 시작하지 않아요.
  3. 힌트: 파이썬은 줄 앞의 빈칸(들여쓰기)을 보고 어떤 문장이 `if`에 딸려 있는지 알아내요. `if`에 딸린 문장은 `if`보다 안쪽에서 시작해야 해요.


[5] if 와 else 의 들여쓰기 위치를 맞추지 않기
    오류 종류 id : cond.else_misaligned
    잡히는 줄    : 4번 줄
----- 코드 -----
n = int(input("숫자: "))
if n % 2 == 0:
        print("짝수")
    else:
        print("홀수")
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 `else`가 어느 `if`와 짝인지 찾지 못하고 멈췄어요.
  2. 의심 지점: 4번 줄 `else` 앞의 빈칸 수와, 짝이 되는 `if` 앞의 빈칸 수를 각각 세어 보세요.
  3. 힌트: `else`는 짝이 되는 `if`와 정확히 같은 위치에서 시작해야 해요. 한 칸만 달라도 파이썬은 짝으로 보지 않아요.


############################################################
# 반복문
############################################################

[6] for 문이나 while 문 뒤에 콜론을 빠뜨리기
    오류 종류 id : loop.missing_colon
    잡히는 줄    : 2번 줄
----- 코드 -----
total = 0
for i in range(1, 11)
    total = total + i
print(total)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 `for`로 시작하는 줄을 읽다가 멈췄어요. 어디까지가 반복 조건이고 어디서부터가 반복할 문장인지 알려 주는 표시를 찾지 못했어요.
  2. 의심 지점: 2번 줄의 맨 끝을 보세요. 기호 하나가 빠져 있어요.
  3. 힌트: `for`, `while`로 시작하는 줄은 언제나 같은 기호로 끝나요. `if` 줄의 끝에 쓰는 기호와 같아요.


[7] 반복할 문장이 반복문 안에 들어가지 않게 들여쓰기 하기
    오류 종류 id : loop.body_not_indented
    잡히는 줄    : 2번 줄
----- 코드 -----
for i in range(5):
print(i)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: `for` 줄 다음에는 반복할 문장이 와야 하는데, 파이썬이 그런 문장을 찾지 못했어요.
  2. 의심 지점: 1번 줄 `for` 바로 아래에 있는 2번 줄을 보세요. `for`보다 안쪽에서 시작하지 않아요.
  3. 힌트: 파이썬은 줄 앞의 빈칸(들여쓰기)을 보고 어떤 문장을 반복할지 알아내요. 반복할 문장은 `for`보다 안쪽에서 시작해야 해요.


############################################################
# 중첩 반복문
############################################################

[8] 안쪽 반복문을 바깥쪽과 같은 들여쓰기에 쓰기
    오류 종류 id : nested.inner_same_indent
    잡히는 줄    : 2번 줄
----- 코드 -----
for i in range(2, 10):
for j in range(1, 10):
    print(i, "x", j, "=", i * j)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 반복문 줄 다음에는 그 안에서 반복할 문장이 와야 하는데, 파이썬이 그런 문장을 찾지 못했어요.
  2. 의심 지점: 1번 줄과 2번 줄에 반복문이 하나씩 있어요. 두 줄이 시작하는 위치를 견줘 보세요.
  3. 힌트: 두 반복문이 같은 위치에서 시작하면 파이썬은 '안과 밖'이 아니라 서로 상관없는 '위와 아래'로 읽어요. 안쪽 반복문은 바깥쪽 반복문보다 안쪽에서 시작해야 해요.
  4. 추가 힌트: 안쪽 반복문을 옮길 때는 그 반복문에 딸린 문장들도 함께 같은 만큼 더 안쪽으로 옮겨야 해요.


############################################################
# 함수
############################################################

[9] 함수 정의 뒤에 콜론을 빠뜨리기
    오류 종류 id : func.missing_colon
    잡히는 줄    : 1번 줄
----- 코드 -----
def add(a, b)
    return a + b

print(add(3, 4))
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 `def`로 시작하는 줄을 읽다가 멈췄어요. 함수 이름과 매개변수 다음에, 여기서부터 본문이라고 알려 주는 표시를 찾지 못했어요.
  2. 의심 지점: 1번 줄의 맨 끝을 보세요. 기호 하나가 빠져 있어요.
  3. 힌트: `def`로 시작하는 줄도 `if`나 `for` 줄과 같은 기호로 끝나요.


[10] 함수 정의에서 괄호를 빠뜨리기
    오류 종류 id : func.def_missing_paren
    잡히는 줄    : 1번 줄
----- 코드 -----
def hello:
    print("안녕하세요")

hello()
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 함수를 만드는 줄을 읽다가 멈췄어요. 함수 이름 다음에 꼭 와야 하는 것이 빠져 있어요.
  2. 의심 지점: 1번 줄에서 함수 이름 바로 뒤를 보세요.
  3. 힌트: 함수 이름 뒤에는 받을 값(매개변수)을 적는 자리가 꼭 있어야 해요. 받을 값이 하나도 없어도 그 자리는 비워 둔 채로 써 줘야 해요.


[11] 함수 본문을 들여쓰기 하지 않기
    오류 종류 id : func.body_not_indented
    잡히는 줄    : 2번 줄
----- 코드 -----
def square(x):
return x * x

print(square(5))
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: `def` 줄 다음에는 함수가 할 일이 와야 하는데, 파이썬이 그런 문장을 찾지 못했어요.
  2. 의심 지점: 1번 줄 `def` 바로 아래에 있는 2번 줄을 보세요. `def`보다 안쪽에서 시작하지 않아요.
  3. 힌트: 파이썬은 줄 앞의 빈칸(들여쓰기)을 보고 어디까지가 함수 안인지 알아내요. 함수가 할 일은 `def`보다 안쪽에서 시작해야 해요.


############################################################
# 변수
############################################################

[12] 변수 이름 규칙을 어기기 (숫자로 시작)
    오류 종류 id : var.name_starts_with_digit
    잡히는 줄    : 1번 줄
----- 코드 -----
1st_score = 90
print(1st_score)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 변수 이름을 읽다가 멈췄어요. 이름이 아니라 숫자가 시작되는 줄 알았는데 뒤에 글자가 이어졌기 때문이에요.
  2. 의심 지점: 1번 줄에서 `=` 왼쪽에 쓴 이름의 첫 글자를 보세요.
  3. 힌트: 변수 이름은 숫자로 시작할 수 없어요. 숫자는 이름의 중간이나 끝에만 쓸 수 있어요.


[13] 변수 이름 규칙을 어기기 (빈칸 포함)
    오류 종류 id : var.name_with_space
    잡히는 줄    : 1번 줄
----- 코드 -----
my name = "철수"
print(my name)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 변수 이름을 읽다가 멈췄어요. 이름 하나가 올 자리에 단어가 여러 개 있어요.
  2. 의심 지점: 1번 줄에서 `=` 왼쪽을 보세요. 단어 사이에 빈칸이 있어요.
  3. 힌트: 변수 이름에는 빈칸을 넣을 수 없어요. 파이썬은 빈칸으로 나뉜 단어를 서로 다른 이름으로 읽어요.
  4. 추가 힌트: 여러 단어를 이름 하나로 쓰고 싶을 때 빈칸 대신 넣는 기호가 있어요. 교과서나 다른 코드에서 여러 단어로 된 변수 이름을 어떻게 썼는지 떠올려 보세요.


############################################################
# 문법
############################################################

[14] 괄호를 닫지 않기
    오류 종류 id : syntax.unclosed_bracket
    잡히는 줄    : 2번 줄
----- 코드 -----
numbers = [3, 1, 2]
print(max(numbers)
print("끝")
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 코드를 끝까지 읽었는데도 열어 둔 괄호의 짝을 찾지 못했어요.
  2. 의심 지점: 2번 줄에서 `(`로 연 괄호를 보세요.
  3. 힌트: 여는 괄호와 닫는 괄호는 개수가 같아야 해요. 그 줄의 괄호를 안쪽부터 하나씩 짝지어 보세요.


[15] 따옴표를 닫지 않기
    오류 종류 id : syntax.unclosed_string
    잡히는 줄    : 1번 줄
----- 코드 -----
name = "철수
print(name)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 문자열이 어디에서 끝나는지 찾지 못했어요. 따옴표로 시작한 글이 끝나지 않았어요.
  2. 의심 지점: 1번 줄에서 따옴표로 시작한 부분을 보세요.
  3. 힌트: 문자열은 시작할 때 쓴 것과 같은 종류의 따옴표로 끝나야 해요. 작은따옴표로 시작했는지 큰따옴표로 시작했는지 보고, 끝에도 같은 것이 있는지 확인해 보세요.


[16] 파이썬이 읽지 못하는 글자 쓰기 (전각 기호 등)
    오류 종류 id : syntax.fullwidth_char
    잡히는 줄    : 1번 줄
----- 코드 -----
print（"안녕하세요"）
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 알아보지 못하는 글자를 만나서 멈췄어요.
  2. 의심 지점: 1번 줄에 있는 `（` 글자를 보세요. 평소에 쓰던 기호와 모양이 조금 달라요.
  3. 힌트: 한글 입력 상태에서 친 괄호·따옴표나 문서에서 복사해 온 기호는 눈으로는 비슷해도 파이썬에게는 다른 글자예요. 그 글자를 지우고 영문 입력 상태에서 다시 쳐 보세요.


[17] 필요 없는 곳에 들여쓰기 하기
    오류 종류 id : syntax.unexpected_indent
    잡히는 줄    : 2번 줄
----- 코드 -----
x = 10
    y = 20
print(x + y)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 들여쓰기가 필요 없는 자리에서 들여쓴 줄을 만나서 멈췄어요.
  2. 의심 지점: 2번 줄이 바로 윗줄보다 안쪽에서 시작해요. 그런데 윗줄은 `if`, `for`, `def`처럼 딸린 문장을 거느리는 줄이 아니에요.
  3. 힌트: 들여쓰기는 어떤 줄에 딸린 문장에만 써요. 이 줄이 딸려 있는 줄이 없다면 윗줄과 같은 위치에서 시작해야 해요.


[18] 들여쓰기 위치를 앞의 줄과 맞추지 않기
    오류 종류 id : syntax.indent_mismatch
    잡히는 줄    : 4번 줄
----- 코드 -----
n = 3
if n > 0:
    print("양수")
  print("확인 끝")
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 파이썬이 들여쓰기를 줄인 줄을 읽다가 멈췄어요. 그 줄이 시작하는 위치가 위쪽의 어떤 줄과도 맞지 않아요.
  2. 의심 지점: 4번 줄 앞의 빈칸 수를 세어 보고, 위쪽 줄들의 빈칸 수와 견줘 보세요.
