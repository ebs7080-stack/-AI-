논리 오류 검증 예시 코드
============================================================

코딩입문 중고등학생을 위한 단계적 피드백 웹서비스의 논리 오류 규칙(app/analyzer/rules/)이 잡는
30가지 실수마다 예시 코드를 하나씩 모았다. '----- 코드 -----' 아래의 내용을 학생 화면의
코드 입력 칸에 그대로 붙여 넣고 제출하면, 그 실수에 해당하는 힌트가 나온다. 아래 힌트 문구는 기본값이며,
교사가 '오류별 힌트' 화면에서 고쳤다면 고친 문구가 나온다.

- 모든 예시는 실제 분석기로 확인했다 (Python 3.12 기준). 이 파일은 그 확인 결과로 만든다.
- 문법 오류가 있으면 문법 오류만 알려 준다. 논리 오류는 문법이 맞을 때만 찾는다.
- 한 번에 하나만 알려 준다. 여러 개가 있으면 '실행하면 멈춤 → 끝나지 않음 → 결과가 틀림' 순서로
  먼저인 것을 보여 주고, 고쳐서 다시 내면 다음 것이 나온다.
- 규칙은 오탐보다 미탐을 택한다. 과제에 따라 맞을 수도 있는 모양(최댓값을 0 으로 시작 등)은 잡지 않는다.
- 줄 번호는 '----- 코드 -----' 바로 다음 줄을 1번 줄로 센 것이다.


############################################################
# 변수
############################################################

[1] sum, max, list, str 같은 내장 함수 이름을 변수 이름으로 쓰기
    오류 종류 id : var.builtin_shadowed
    잡히는 줄    : 1번 줄
----- 코드 -----
sum = 0
for n in [3, 5, 7]:
    sum = sum + n
print("합계:", sum)
print("다시 계산:", sum([3, 5, 7]))
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 코드를 실행하면 `sum(...)`을 부르는 줄에서 멈출 거예요. 파이썬이 원래 가지고 있던 `sum` 함수가 더 이상 함수가 아니게 됐어요.
  2. 의심 지점: 1번 줄에서 `sum`이라는 이름에 값을 넣었어요. 그 아래 5번 줄에서 같은 이름을 함수처럼 부르고 있어요.
  3. 힌트: `sum`은 파이썬이 미리 만들어 둔 함수의 이름이에요. 내가 만든 변수와 그 함수가 같은 이름을 나눠 쓸 수 있을까요? 변수 이름을 무엇으로 하면 좋을지 생각해 보세요.


[2] 문자열과 숫자를 + 로 이어 붙이기
    오류 종류 id : var.str_plus_number
    잡히는 줄    : 2번 줄
----- 코드 -----
age = 15
print("내 나이는 " + age + "살이에요.")
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 코드를 실행하면 글자와 숫자를 더하는 곳에서 멈출 거예요. 파이썬은 글자와 숫자를 바로 더하지 못해요.
  2. 의심 지점: 2번 줄의 `'내 나이는 ' + age`을 보세요. `+` 양쪽에 있는 것이 각각 글자인지 숫자인지 따져 보세요.
  3. 힌트: 글자끼리는 이어 붙일 수 있고, 숫자끼리는 더할 수 있어요. 숫자를 글자 사이에 넣어 보여 주고 싶다면, 숫자를 무엇으로 바꿔야 할까요? `print`에 여러 값을 나눠 넘기는 방법도 떠올려 보세요.


[3] input()으로 받은 값을 숫자로 바꾸지 않고 계산하기
    오류 종류 id : var.input_not_converted
    잡히는 줄    : 3번 줄
----- 코드 -----
a = input("첫 번째 수: ")
b = int(input("두 번째 수: "))
print("두 수의 합:", a + b)
print("첫 번째 수의 두 배:", a * 2)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 코드를 실행하면 계산하는 곳에서 멈추거나, 생각과 다른 결과(예: `33`)가 나올 거예요.
  2. 의심 지점: 3번 줄에서 `a`을 숫자와 함께 계산하고 있어요. `a`에는 어떤 종류의 값이 들어 있을까요?
  3. 힌트: `input()`은 키보드로 받은 것을 언제나 글자(문자열)로 줘요. `3`을 입력해도 숫자 3이 아니라 글자 "3"이에요. 숫자로 계산하려면 받은 값을 어떻게 해야 할까요?


[4] 계산만 하고 결과를 변수에 저장하지 않기
    오류 종류 id : var.result_not_stored
    잡히는 줄    : 3번 줄
----- 코드 -----
score = 80
bonus = 5
score + bonus
print("최종 점수:", score)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 계산은 하지만 그 결과가 어디에도 남지 않아서, 실행해도 변수의 값이 바뀌지 않아요.
  2. 의심 지점: 3번 줄의 `score + bonus`을 보세요. 이 줄이 실행된 뒤 계산한 값은 어디에 있을까요?
  3. 힌트: 파이썬은 계산한 값을 따로 담으라고 하지 않으면 바로 버려요. 계산한 값을 변수에 담으려면 어떻게 써야 했는지 떠올려 보세요.


[5] 값을 넣으려다 == 로 비교만 하기
    오류 종류 id : var.eq_as_assign
    잡히는 줄    : 2번 줄
----- 코드 -----
count = 0
count == 10
print(count)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 줄은 실행돼도 아무 변수의 값도 바꾸지 않아요. 두 값이 같은지 묻기만 하고 그 대답을 버려요.
  2. 의심 지점: 2번 줄의 `count == 10`을 보세요. 여기서 `count`에 값을 넣으려고 했나요, 아니면 같은지 물어보려고 했나요?
  3. 힌트: `==`는 '두 값이 같은가?'를 묻는 기호예요. 변수에 값을 넣을 때 쓰는 기호는 따로 있어요.


[6] 두 변수의 값을 임시 변수 없이 서로 바꾸기 (a = b, b = a)
    오류 종류 id : var.swap_without_temp
    잡히는 줄    : 3번 줄
----- 코드 -----
a = 1
b = 2
a = b
b = a
print(a, b)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 두 변수의 값을 바꾸려고 했지만, 실행하고 나면 두 변수에 같은 값이 들어 있을 거예요.
  2. 의심 지점: 3번 줄과 4번 줄을 차례로 따라가 보세요. 3번 줄이 끝났을 때 `a`의 원래 값은 어디에 남아 있나요?
  3. 힌트: `a`에 새 값을 넣는 순간 원래 값은 사라져요. 사라지기 전에 원래 값을 잠깐 맡겨 둘 곳이 있다면 어떨까요? 파이썬에는 두 값을 한 줄에 함께 바꾸는 방법도 있어요.


[7] 변수 이름과 문자열을 혼동하기 (print(name) 대신 print("name") 쓰기)
    오류 종류 id : var.quoted_variable
    잡히는 줄    : 3번 줄
----- 코드 -----
name = input("이름: ")
print("안녕하세요,")
print("name")
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 변수에 들어 있는 값 대신 변수의 이름 글자가 그대로 화면에 나올 거예요.
  2. 의심 지점: 3번 줄의 `print`에 넘긴 `"name"`을 보세요. 따옴표로 감싼 것과 `name` 변수는 같은 것일까요?
  3. 힌트: 따옴표로 감싸면 파이썬은 그것을 글자 그대로로 봐요. 변수에 담긴 값을 꺼내 쓰려면 이름을 어떻게 써야 할까요?

# 조건문
############################################################

[8] input()으로 받은 문자열과 숫자를 == 로 비교하기
    오류 종류 id : cond.input_str_compare
    잡히는 줄    : 2번 줄
----- 코드 -----
answer = input("3 + 4 = ? ")
if answer == 7:
    print("정답!")
else:
    print("틀렸어요.")
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 무엇을 입력해도 조건이 생각대로 참이 되지 않거나, 크기를 비교하는 곳에서 멈출 거예요.
  2. 의심 지점: 2번 줄에서 `answer`을 숫자와 비교하고 있어요. `answer`에는 숫자가 들어 있을까요, 글자가 들어 있을까요?
  3. 힌트: `input()`으로 받은 값은 언제나 글자예요. 글자 "3"과 숫자 3은 파이썬에게 서로 다른 값이에요. 둘을 같은 종류로 맞추려면 어떻게 해야 할까요?


[9] x == 1 or 2 처럼 or 조건을 잘못 쓰기
    오류 종류 id : cond.or_constant
    잡히는 줄    : 2번 줄
----- 코드 -----
menu = int(input("메뉴 번호: "))
if menu == 1 or 2:
    print("음료를 골랐어요.")
else:
    print("디저트를 골랐어요.")
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: `menu`에 어떤 값을 넣어도 이 조건은 언제나 참이 될 거예요.
  2. 의심 지점: 2번 줄 조건의 `or` 뒤쪽에 있는 `2`만 따로 떼어 읽어 보세요.
  3. 힌트: `or` 양쪽은 각각 따로 참·거짓을 판단해요. `2` 혼자는 무엇과 비교하고 있나요? 비교하지 않은 값 혼자는 참일까요, 거짓일까요?


[10] 넓은 조건을 먼저 검사해서 뒤의 조건이 실행되지 않게 하기
    오류 종류 id : cond.wide_condition_first
    잡히는 줄    : 4번 줄
----- 코드 -----
score = int(input("점수: "))
if score >= 60:
    grade = "D"
elif score >= 70:
    grade = "C"
elif score >= 90:
    grade = "A"
else:
    grade = "F"
print(grade)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 어떤 값을 넣어도 실행되지 않는 조건이 있어요.
  2. 의심 지점: 4번 줄의 조건이 참이 되는 `score` 값을 하나 떠올려 보세요. 그 값이면 2번 줄의 조건은 이미 참이지 않나요?
  3. 힌트: `if`와 `elif`는 위에서부터 차례로 검사해서 처음 참이 된 곳 하나만 실행해요. 더 넓은 범위와 더 좁은 범위 중 어느 쪽을 먼저 물어봐야 할까요?



############################################################
# 반복문
############################################################

[11] while True 에서 break 를 빠뜨리기
    오류 종류 id : loop.while_true_no_break
    잡히는 줄    : 1번 줄
----- 코드 -----
while True:
    word = input("단어 (그만하려면 q): ")
    print(word, "의 길이:", len(word))
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 반복문은 끝나지 않을 거예요. 반복을 멈추게 하는 문장이 하나도 없어요.
  2. 의심 지점: 1번 줄의 `while` 본문을 보세요. 어떤 일이 생기면 반복을 그만두어야 하나요?
  3. 힌트: 조건이 언제나 참인 `while`은 스스로는 멈추지 않아요. 원하는 일이 생겼을 때 반복을 빠져나가는 키워드를 떠올려 보세요.


[12] while 문에서 조건을 바꾸는 문장을 빠뜨려 무한 반복하기
    오류 종류 id : loop.while_no_update
    잡히는 줄    : 3번 줄
----- 코드 -----
i = 1
total = 0
while i <= 10:
    total = total + i
print(total)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 조건이 처음에 참이면 이 반복문은 끝나지 않을 거예요.
  2. 의심 지점: 3번 줄의 `while` 조건에 쓴 `i`은 반복할 때마다 어떻게 바뀌나요? 본문에서 찾아보세요.
  3. 힌트: 조건이 언젠가 거짓이 되려면 반복문 안에서 무엇인가 바뀌어야 해요. 한 번 돌 때마다 `i`이 어떻게 바뀌어야 할지 생각해 보세요.


[13] 개수를 셀 때 count += 1 대신 count = 1 이라고 쓰기
    오류 종류 id : loop.count_set_to_one
    잡히는 줄    : 5번 줄
----- 코드 -----
scores = [90, 45, 72, 30, 88]
count = 0
for s in scores:
    if s >= 60:
        count = 1
print("합격자 수:", count)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 조건에 맞는 것이 여러 개여도 `count`은 1보다 커지지 않을 거예요.
  2. 의심 지점: 5번 줄을 보세요. 이 줄이 두 번, 세 번 실행되면 `count`은 얼마가 되나요?
  3. 힌트: 개수를 세려면 '1로 만든다'가 아니라 '지금 값에서 하나 늘린다'여야 해요. 지금 값을 바탕으로 새 값을 만드는 식을 떠올려 보세요.


[14] for i in 리스트 에서 i 가 값인데 인덱스처럼 쓰기 (a[i])
    오류 종류 id : loop.value_as_index
    잡히는 줄    : 4번 줄
----- 코드 -----
scores = [90, 80, 70]
total = 0
for i in scores:
    total = total + scores[i]
print(total)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 코드를 실행하면 엉뚱한 칸의 값을 꺼내거나, 리스트 범위를 벗어났다며 멈출 수 있어요.
  2. 의심 지점: 3번 줄의 `for i in scores`에서 `i`에는 무엇이 들어 있나요? 4번 줄에서는 그것을 `scores[i]`처럼 칸 번호로 쓰고 있어요.
  3. 힌트: `for` 뒤의 변수에는 리스트의 칸 번호가 아니라 칸에 든 값이 하나씩 들어와요. 값을 그대로 쓰면 될까요, 아니면 칸 번호가 정말 필요한가요?


[15] 반복문으로 리스트를 순회하면서 그 리스트의 항목을 지우기
    오류 종류 id : loop.modify_while_iterating
    잡히는 줄    : 4번 줄
----- 코드 -----
nums = [3, -1, -2, 5]
for n in nums:
    if n < 0:
        nums.remove(n)
print(nums)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 반복하는 동안 리스트가 바뀌어서, 어떤 항목은 건너뛰거나 반복이 끝나지 않을 수 있어요.
  2. 의심 지점: 2번 줄에서 `nums`을 하나씩 돌고 있는데, 4번 줄에서 바로 그 `nums`을 바꾸고 있어요.
  3. 힌트: `for`는 리스트의 몇 번째 칸까지 왔는지 기억하며 돌아요. 도는 중에 칸이 지워지거나 늘어나면 어떻게 될까요? 결과를 담을 리스트를 따로 두는 방법을 생각해 보세요.


[16] 반복문 안에서 return 을 써서 첫 번째 반복에서 함수가 끝나기
    오류 종류 id : loop.return_in_loop
    잡히는 줄    : 3번 줄
----- 코드 -----
def is_prime(n):
    for d in range(2, n):
        if n % d == 0:
            return False
        else:
            return True

print(is_prime(9))
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 반복문은 첫 번째 값만 보고 함수가 끝나 버릴 거예요. 나머지 값은 검사하지 않아요.
  2. 의심 지점: 2번 줄의 반복문에서 3번 줄까지 왔을 때, 어떤 길로 가도 `return`을 만나지 않나요?
  3. 힌트: `return`을 만나면 반복문뿐 아니라 함수 전체가 바로 끝나요. 모든 값을 다 본 뒤에야 알 수 있는 대답은 반복문의 안과 밖 중 어디에서 돌려줘야 할까요?

[17] 안쪽과 바깥쪽 반복문에 같은 변수 이름(i)을 쓰기
    오류 종류 id : nested.same_loop_var
    잡히는 줄    : 2번 줄
----- 코드 -----
for i in range(1, 4):
    for i in range(1, 4):
        print(i, end=" ")
    print()
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 안쪽 반복이 바깥쪽 반복의 변수를 덮어써서, 바깥쪽 값이 생각과 다르게 바뀔 거예요.
  2. 의심 지점: 1번 줄의 바깥쪽 `for`와 2번 줄의 안쪽 `for`가 둘 다 `i`을 쓰고 있어요.
  3. 힌트: 안쪽 반복이 돌 때 `i`에는 안쪽 값이 들어가요. 바깥쪽에서 몇 번째인지와 안쪽에서 몇 번째인지를 따로 기억하려면 어떻게 해야 할까요?


[18] 2차원 리스트를 [[0] * n] * m 으로 만들어 모든 행이 함께 바뀌기
    오류 종류 id : nested.shared_rows
    잡히는 줄    : 1번 줄
----- 코드 -----
board = [[0] * 3] * 3
board[0][0] = 1
print(board)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 한 칸만 바꿨는데 모든 줄(행)의 같은 칸이 함께 바뀔 거예요.
  2. 의심 지점: 1번 줄에서 리스트를 `*`로 늘려 여러 줄을 만들었어요. 이렇게 만든 줄들은 서로 다른 리스트일까요?
  3. 힌트: 리스트를 `*`로 늘리면 같은 리스트를 가리키는 것이 여러 개 생길 뿐 새 리스트가 만들어지지 않아요. 줄마다 새 리스트를 하나씩 만들려면 무엇을 써야 할까요?

[19] 필요한 인자를 전달하지 않기
    오류 종류 id : func.wrong_arg_count
    잡히는 줄    : 4번 줄
----- 코드 -----
def area(width, height):
    return width * height

print(area(5))
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 코드를 실행하면 `area` 함수를 부르는 곳에서 멈출 거예요. 넘겨준 값의 개수가 맞지 않아요.
  2. 의심 지점: 4번 줄에서 `area`에 값을 1개 넘겼어요. 1번 줄의 정의에서는 몇 개를 받기로 했나요?
  3. 힌트: 함수를 부를 때 넘기는 값은 정의의 괄호 안에 쓴 매개변수에 하나씩 차례로 들어가요. `area`에는 2개가 필요해요. 빠지거나 남는 값이 없는지 맞춰 보세요.


[20] 여러 값을 return 할 때 받는 쪽의 변수 개수를 맞추지 않기
    오류 종류 id : func.unpack_mismatch
    잡히는 줄    : 4번 줄
----- 코드 -----
def min_max(nums):
    return min(nums), max(nums)

low, high, middle = min_max([3, 9, 1])
print(low, high, middle)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 코드를 실행하면 함수의 결과를 나눠 담는 곳에서 멈출 거예요. 돌려준 값과 받는 변수의 개수가 달라요.
  2. 의심 지점: 2번 줄의 `return`은 값을 2개 돌려줘요. 4번 줄에서는 변수 3개로 받고 있어요.
  3. 힌트: 여러 값을 한꺼번에 받을 때는 왼쪽 변수와 오른쪽 값이 하나씩 짝을 이뤄야 해요. 어느 쪽 개수를 맞춰야 할지 생각해 보세요.


[21] 전역 변수를 함수 안에서 바꾸려다 global 없이 오류가 나기
    오류 종류 id : func.global_without_decl
    잡히는 줄    : 4번 줄
----- 코드 -----
score = 0

def add_point():
    score += 10

add_point()
print(score)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 함수를 부르면 `score`을 바꾸는 곳에서 멈출 거예요. 함수 안에서는 아직 값이 없는 변수로 보여요.
  2. 의심 지점: 4번 줄에서 함수 밖에서 만든 `score`을 함수 안에서 바꾸고 있어요.
  3. 힌트: 함수 안에서 어떤 이름에 값을 넣으면 파이썬은 그것을 함수 안에서만 쓰는 새 변수로 봐요. 함수 밖의 변수를 바꾸겠다고 알려 주는 방법이 있어요. 값을 매개변수로 받고 돌려주는 방법도 생각해 보세요.


[22] 재귀 함수에서 종료 조건을 빠뜨리기
    오류 종류 id : func.recursion_no_base
    잡히는 줄    : 1번 줄
----- 코드 -----
def factorial(n):
    return n * factorial(n - 1)

print(factorial(5))
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 함수를 부르면 자기 자신을 끝없이 다시 불러서, 결국 너무 깊이 들어갔다며 멈출 거예요.
  2. 의심 지점: 1번 줄의 `factorial` 함수는 2번 줄에서 자기 자신을 불러요. 언제 다시 부르기를 멈추나요?
  3. 힌트: 재귀 함수에는 '이 경우엔 더 부르지 않고 바로 답을 돌려준다'는 가장 작은 경우가 필요해요. `factorial`에서 가장 작은 경우는 무엇이고, 그때의 답은 무엇일까요?


[23] return 과 print 를 혼동하기
    오류 종류 id : func.print_not_return
    잡히는 줄    : 4번 줄
----- 코드 -----
def add(a, b):
    print(a + b)

result = add(3, 4)
print("두 배:", result * 2)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: `add` 함수가 화면에 결과를 보여 주긴 하지만, 함수를 부른 자리에는 아무 값도 돌아오지 않아요(`None`).
  2. 의심 지점: 4번 줄에서 `add`의 결과를 쓰고 있어요. 1번 줄의 `add`은 결과를 돌려주나요, 화면에 보여 주기만 하나요?
  3. 힌트: `print`는 화면에 보여 주기만 하고 값을 돌려주지는 않아요. 함수를 부른 곳으로 값을 돌려보낼 때 쓰는 키워드는 따로 있어요.


[24] return 이 없는 함수의 결과(None)를 변수에 저장해서 계산에 쓰기
    오류 종류 id : func.none_used
    잡히는 줄    : 4번 줄
----- 코드 -----
def double(n):
    n = n * 2

answer = double(5)
print(answer)
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: `double` 함수는 값을 돌려주지 않아서, 그 결과는 언제나 `None`(값 없음)이에요.
  2. 의심 지점: 4번 줄에서 `double`의 결과를 쓰고 있어요. 1번 줄의 `double` 안에 값을 돌려주는 문장이 있나요?
  3. 힌트: 함수가 계산한 값을 부른 곳에서 쓰려면, 함수가 그 값을 돌려줘야 해요. 값을 돌려줄 때 쓰는 키워드를 떠올려 보세요.


[25] 조건에 따라 값을 반환하지 않는 경우가 생기게 하기
    오류 종류 id : func.missing_return
    잡히는 줄    : 2번 줄
----- 코드 -----
def grade(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"

print(grade(65))
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 어떤 값을 넣으면 `grade` 함수가 아무것도 돌려주지 않고(`None`) 끝날 거예요.
  2. 의심 지점: 2번 줄의 `if`·`elif`에서 어느 조건에도 맞지 않는 값이 들어오면, `grade`은 어디에서 끝나나요?
  3. 힌트: 모든 경우에 값을 돌려주는지 확인하려면, 조건에 하나도 맞지 않는 경우를 일부러 떠올려 보세요. 그 경우에는 무엇을 돌려줘야 할까요?


[26] 함수가 반환한 값을 받지 않고 호출만 하기
    오류 종류 id : func.return_ignored
    잡히는 줄    : 4번 줄
----- 코드 -----
def square(n):
    return n * n

square(4)
print("4의 제곱을 계산했어요.")
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: `square` 함수가 값을 계산해서 돌려주지만, 그 값을 아무도 받지 않아서 바로 사라져요.
  2. 의심 지점: 4번 줄에서 `square`을 부르기만 하고 결과는 쓰지 않아요. 1번 줄의 `square`은 무엇을 돌려주나요?
  3. 힌트: 돌려받은 값은 변수에 담거나, 바로 다른 계산이나 출력에 써야 남아요. 이 값을 어디에 쓰려고 했는지 생각해 보세요.


[27] 함수 호출 시 괄호를 빠뜨리기
    오류 종류 id : func.missing_call_parens
    잡히는 줄    : 4번 줄
----- 코드 -----
def greet():
    print("안녕하세요!")

greet
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 줄은 실행돼도 아무 일도 일어나지 않아요. 함수가 불리지 않았어요.
  2. 의심 지점: 4번 줄에 `greet`이라고 이름만 썼어요. 함수를 '부르는' 모양인지 확인해 보세요.
  3. 힌트: 함수 이름만 쓰면 함수를 가리키기만 해요. 함수를 실제로 실행하려면 이름 뒤에 무엇을 붙였는지, 다른 줄에서 함수를 부른 모양과 견줘 보세요.


[28] return 뒤에 코드를 써서 실행되지 않게 하기
    오류 종류 id : func.unreachable
    잡히는 줄    : 3번 줄
----- 코드 -----
def average(a, b):
    return (a + b) / 2
    print("평균을 계산했어요.")

print(average(3, 4))
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 실행되지 않는 줄이 있어요. 그 줄에 쓴 일은 한 번도 일어나지 않아요.
  2. 의심 지점: 2번 줄의 `return` 바로 아래 3번 줄을 보세요.
  3. 힌트: `return`을 만나면 함수는 그 자리에서 끝나요. 3번 줄의 일이 꼭 필요하다면 `return`보다 앞과 뒤 중 어디에 있어야 할까요?


[29] 같은 이름의 함수를 두 번 정의하기 (뒤에 쓴 함수만 남음)
    오류 종류 id : func.defined_twice
    잡히는 줄    : 4번 줄
----- 코드 -----
def hello():
    print("안녕")

def hello():
    print("반가워")

hello()
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: `hello`이라는 함수가 두 번 만들어져서, 앞에서 만든 `hello`은 사라져요.
  2. 의심 지점: 1번 줄과 4번 줄에서 모두 `hello`을 정의했어요.
  3. 힌트: 같은 이름으로 다시 정의하면 앞의 것을 덮어써요. 두 함수가 서로 다른 일을 해야 한다면 이름을 어떻게 하면 좋을까요?


[30] 함수 이름을 변수 이름으로 덮어쓰기
    오류 종류 id : func.name_overwritten
    잡히는 줄    : 4번 줄
----- 코드 -----
def total(nums):
    return sum(nums)

total = 0
print(total([1, 2, 3]))
----- 힌트 (한 단계씩 열림) -----
  1. 관찰: 이 코드를 실행하면 `total(...)`을 부르는 곳에서 멈출 거예요. `total`이 더 이상 함수가 아니에요.
  2. 의심 지점: 4번 줄에서 함수 이름인 `total`에 값을 넣었어요. 그 아래 5번 줄에서 `total`을 함수처럼 부르고 있어요.
  3. 힌트: 함수와 변수는 이름을 나눠 쓸 수 없어요. 같은 이름에 값을 넣으면 함수가 사라져요. 변수 이름을 함수 이름과 다르게 지어 보세요.
