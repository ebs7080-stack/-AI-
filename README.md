# 정적 분석을 이용한 파이썬 실습 지도 지원 플랫폼

코딩을 처음 배우는 중·고등학생을 위한 파이썬 단계적 피드백 웹서비스입니다. 학생이 제출한 코드를 정적 분석해 정답 대신 단계적 힌트를 주고, 먼저 고친 학생이 친구를 돕게 하며, 교사에게는 학급의 오류 통계를 보여 줍니다.

> 처음에는 LLM 기반 에이전트를 목표로 시작했지만, 지금 구현은 **LLM 없이 규칙 기반 정적 분석**으로 동작합니다. LLM은 앞으로 보조 수단으로 검토할 항목입니다.

## 주요 기능

### 학생

- 교실 코드와 학번으로 입장합니다. 교사가 명단에 등록한 학번만 들어올 수 있습니다.
- 코드를 고칠 때마다 새 버전으로 쌓이고, 이전 버전과 달라진 줄을 비교해 볼 수 있습니다.
- 힌트는 정답 코드를 바로 보여 주지 않고, 학생이 요청할 때 한 단계씩(관찰 → 의심 지점 → 힌트) 열립니다.
- 자기 코드를 다 고친 학생은 도움 시간에 같은 교실의 친구와 무작위로 짝이 되어 채팅으로 도울 수 있습니다. 채팅에서 정답 코드를 통째로 보내면 차단합니다.

### 교사

- 회원 가입 후 교실을 여러 개 만들고, 교실마다 학번 명단을 관리합니다.
- 교실 대시보드에서 요약, 수업 전에 볼 오류, 날짜별 제출, 오류 유형별 통계, 학생별 현황과 오답률을 봅니다. 학생의 코드 원문과 채팅 내용은 대시보드에 나오지 않습니다.
- 친구 돕기와 채팅을 허용할 도움 시간을 열고 닫으며, 짝이 된 학생끼리 이름을 가릴 수 있습니다.
- 오류별 힌트 문구를 직접 고칠 수 있습니다.

### 찾아내는 오류 (58가지)

| 구분 | 개수 | 예 |
| --- | --- | --- |
| 문법 오류 | 19 | 콜론 빠짐, 조건문에 `=` 사용, 괄호를 닫지 않음 |
| 논리 오류 | 30 | 끝나지 않는 `while`, `x == 1 or 2`, 문자열과 숫자 더하기 |
| 이름 오류 | 9 | 변수 이름 오타, 만들기 전에 사용, 함수 안 변수를 밖에서 사용 |

문법 오류가 있으면 그 오류를 먼저 알려 줍니다. 문법이 맞으면 실행을 멈추게 하는 오류, 끝나지 않는 오류, 결과가 틀리는 오류 순으로 **한 번에 하나만** 보여 줍니다. 잘못 지적하는 일을 줄이려고 확실한 경우만 찾기 때문에 놓치는 오류가 있을 수 있습니다. 학생 코드를 실제로 실행하지는 않습니다.

## 실행 방법

Windows와 Python 3.12 기준입니다.

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m uvicorn app.main:app --reload
```

`start.bat`을 더블클릭해도 서버가 켜지고 브라우저가 열립니다. 끌 때는 `stop.bat`을 실행합니다.

- 학생 화면: http://127.0.0.1:8000
- 교사 화면: http://127.0.0.1:8000/teacher.html

처음 사용할 때의 순서는 다음과 같습니다.

1. 교사 화면에서 회원 가입을 하고 교실을 만듭니다.
2. 학생 학번을 명단에 등록하고 교실 코드를 학생에게 알려 줍니다.
3. 학생이 교실 코드와 학번으로 들어와 코드를 제출합니다.
4. 친구 돕기를 쓰려면 교사가 도움 시간을 엽니다.

### 테스트

```bash
.venv/Scripts/python -m pytest
```

### 시연용 임시 공개

`start_public.bat`은 Cloudflare 터널로 임시 공개 주소를 만듭니다. `cloudflared`가 설치되어 있어야 하고, 주소는 실행할 때마다 바뀝니다.

## 기술 스택

- 백엔드: Python 3.12, FastAPI, SQLite, WebSocket(채팅)
- 프론트엔드: 빌드 과정 없는 HTML, CSS, JavaScript
- 코드 분석: 파이썬 표준 라이브러리 `ast`
- 테스트: pytest

## 폴더 구조

```text
app/            서버 코드 (API, 인증, 채팅, 통계)
app/analyzer/   코드 분석기 (cases.toml: 오류 목록과 힌트 문구, rules/: 논리·이름 검사 규칙)
static/         학생·교사 화면
tests/          자동 테스트
docs/           요구사항, 정적 분석 설계, 오류 예시 코드
```

## 현재 한계와 남은 일

**아직 구현하지 않은 것**

- LLM이 도우미 역할을 대신하거나 보조하는 기능
- 학생 코드를 실행해 검사하는 기능
- 파이썬 외 다른 언어 지원

**아직 하지 않은 것**

- 실제 학생 코드로 탐지율 측정 (목표 80%)
- 실제 수업 적용과 학습자 설문

**사용 시 주의할 점**

- 학생 입장에는 비밀번호가 없어서, 교실 코드와 학번을 아는 사람은 그 학생으로 들어올 수 있습니다. 실제 학생 데이터로 상시 공개하려면 보완이 먼저 필요합니다.
- 채팅 정답 차단은 변수 이름을 바꾸거나 이미지로 보내는 우회를 막지 못합니다.
- 채팅 서버는 프로세스 하나로 실행할 때만 동작합니다.
